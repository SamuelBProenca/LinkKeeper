Entrada e composição

Web / API

Recebe as requisições, verifica a sessão e o CSRF, interpreta comandos com o Core e pede ao Storage para operar o banco. Também serve os arquivos da interface.

Comece neste arquivo
src/LinkKeeper.Web/Program.cs
Dependências / comunicação
Storage e Core via referência transitiva; navegador por HTTP.
Uma distinção importante
Todos os logins válidos entram na mesma conta personal. Não há contas separadas nesta versão.

Referências de projetos: Web → Storage → Core; CLI → Core. A interface conversa com a Web por HTTP. O worker usa Storage dentro do processo Web.

03 / Ciclo de vida

O prazo termina. O histórico fica.

Expirar e arquivar preservam o registro. A coleção padrão mostra os ativos.

Active

Referência da coleção ativa. Pode ter prazo ou ser permanente. A ação de arquivar está disponível.

Expired

O prazo terminou e o estado foi reconciliado. Pode renovar por sete dias na tela ou arquivar.

Archived

Arquivamento explícito. O registro continua consultável; desarquivamento ainda não existe.

Active → Expired → Active por renovação · Active ou Expired → Archived por arquivamento.
