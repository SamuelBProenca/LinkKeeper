# Documentação do LinkKeeper

Comece pelo [guia do projeto](GUIA-DO-PROJETO.md). Ele parte do uso no navegador,
percorre um cadastro até o SQLite e explica a estrutura, regras, API, testes,
histórico e pendências com links para os arquivos reais.

Abra o [mapa visual interativo](mapa-do-projeto.html) diretamente no navegador
para explorar os componentes e avançar pelas etapas de um cadastro ilustrativo.
Ele funciona como um arquivo local e não exige iniciar a aplicação.

| Documento | Quando consultar |
| --- | --- |
| [GUIA-DO-PROJETO.md](GUIA-DO-PROJETO.md) | Entender o estado atual e acompanhar a leitura do código |
| [mapa-do-projeto.html](mapa-do-projeto.html) | Visualizar responsabilidades, dependências e sequência de execução |
| [RESUMPTION.md](RESUMPTION.md) | Ver o que foi recuperado, corrigido, executado e publicado nesta retomada |
| [WEB-STATUS.md](WEB-STATUS.md) | Consultar a entrega web original e requisitos de hospedagem |
| [FOUNDATION.md](FOUNDATION.md) | Consultar decisões e escopo da etapa de fundação |
| [VALIDATION.md](VALIDATION.md) | Consultar o registro de validação da fundação |
| [README da raiz](../README.md) | Encontrar comandos e tarefas do VS Code rapidamente |

Os documentos de fundação e web original são registros das respectivas etapas.
Para saber o que está implementado agora, use o guia e confira a revisão indicada
no início dele. Na edição de 25/10/2026, a implementação está na branch
`codex/resume-validation`; os PRs #2 a #6 estão em rascunho e a main não recebeu merge.

Para o guia em Markdown, o VS Code oferece a prévia por **Ctrl+Shift+V**.
Para o HTML, abra o arquivo no navegador. Nenhuma senha ou dado pessoal faz parte
destes materiais.
